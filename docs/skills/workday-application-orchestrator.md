# Skill: Workday Application Orchestrator

Use this as the top-level skill when moving from a Workday careers URL to a real submitted application.

## Best Use Cases

- end-to-end Workday job hunting
- narrowing the best-fit roles on a Workday board
- deciding whether a role is worth tailoring for
- choosing between browser submission and API submission

## Workflow

1. Start with `workday-job-discovery`.
2. Assess fit honestly and reject weak roles early.
3. Tailor or select the best resume.
4. Choose the apply path:
   - browser if the tenant is new or unstable
   - API if the tenant flow is already proven
5. Submit and log artifacts.
6. Update the tracker.

## Decision Rules

- Prefer API apply after a tenant has been proven cleanly.
- Prefer browser apply when the flow is fragile or not yet mapped.
- Treat hard seniority or location blockers as skips, not clutter.

## Output Expectations

- shortlisted role or roles
- fit assessment
- resume assets used or created
- apply path chosen
- submission status
- tracker and log updates
